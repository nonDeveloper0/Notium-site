DATA SAFETY

데이터 보안 요약

시행일: 2026년 11월 13일 · 운영자: nonDeveloper0

Google Play 데이터 보안 항목에 맞춘 요약입니다. 자세한 내용은 개인정보처리방침을 확인하세요. 앱: Notium (app.notium, v0.2.0 베타)

1. 개발자가 수집하거나 공유하는 데이터

없음. 개발자(운영자)는 서버를 운영하지 않으며 사용자의 노트, 첨부, 계정 정보, 기기 정보를 수집하지 않습니다. 제3자와 공유하는 데이터도 없습니다.

2. 데이터가 저장되는 곳

  • 기기: 노트, 첨부, 설정, 앱 로그, 인증 토큰(OS 보안 저장소)
  • 사용자 본인의 클라우드(선택): Google Drive 앱 전용 숨김 공간, Microsoft OneDrive 앱 폴더
  • 사용자가 고른 폴더(선택, Windows): 로컬 폴더 동기화

클라우드 동기화는 사용자가 직접 켠 경우에만 작동합니다. 데이터는 사용자의 계정으로 사용자의 저장 공간에 저장되며, 개발자는 접근할 수 없습니다.

3. 전송 중 암호화

Google과 Microsoft API와의 통신은 HTTPS로 암호화됩니다. 노트 내용 자체의 종단 간 암호화는 제공한다고 보장하지 않습니다.

4. 광고와 추적

  • 광고: 없음
  • 분석·추적 SDK: 없음
  • 사용 기록·충돌 보고를 개발자에게 전송: 없음
  • 데이터 판매: 없음

5. 삭제 방법

Notium 계정은 없습니다. 사용자가 기기, 클라우드, 동기화 폴더에서 직접 삭제합니다. 단계별 방법은 데이터 삭제 안내를 확인하세요. 앱을 지우거나 연결을 해제해도 클라우드 데이터는 자동 삭제되지 않습니다.

6. 선택 기능과 외부 서비스

  • Google 연결: 권한 openid, email, drive.appdata. Limited Use 요구사항을 준수합니다.
  • Microsoft 연결: 권한 Files.ReadWrite.AppFolder, User.Read, offline_access
  • AI 연결(Windows): 사용자가 연결한 AI 앱에 이 PC의 노트가 전달될 수 있으며, 이후 처리는 해당 AI 서비스의 정책을 따릅니다. Notium은 AI 회사로 노트를 직접 전송하지 않습니다.

7. 문의

지원 페이지 또는 공개 Issues로 문의하세요. 공개 게시물에는 개인정보를 올리지 마세요.
