Notium v0.2.0은 첫 베타입니다. 중요한 자료는 항상 따로 백업해 두세요. (PC: 설정 → 데이터 → 백업)

문의와 버그 제보

  1. GitHub Issues를 엽니다.
  2. 같은 문제가 이미 있는지 검색합니다.
  3. 새 이슈에 앱 버전, 기기(Windows/Android 버전), 재현 순서를 적습니다.
Issues는 공개됩니다. 노트 내용, 개인정보, 비밀번호, 인증 토큰은 올리지 마세요.

운영자: nonDeveloper0 · 릴리스와 다운로드: 전체 릴리스

자주 묻는 질문

동기화는 어떻게 설정하나요?

  1. PC: 설정 → 계정·동기화에서 Google 계정(또는 OneDrive, 로컬 폴더)을 고릅니다.
  2. 이 PC의 노트로 새 저장소 만들기를 선택합니다.
  3. 다른 기기에서 같은 계정으로 로그인하고 기존 저장소에 연결을 선택합니다.

동기화는 백업을 대신하지 않습니다. 연결을 해제해도 클라우드 데이터는 삭제되지 않습니다. 삭제는 데이터 삭제 안내를 따르세요.

AI 앱은 어떻게 연결하나요? (Windows)

처음 실행할 때 이 PC에서 찾은 AI 앱을 고르거나, 나중에 설정 → AI 연결에서 연결합니다. 지원 앱은 Claude Desktop, Claude Code, Codex, Cursor, VS Code Copilot, Gemini CLI입니다. 기본은 읽기 전용입니다. AI 앱을 연결한 뒤에는 그 앱을 다시 시작해야 할 수 있습니다. Notium을 삭제하면 Notium 연결 항목이 정리됩니다.

Android에서 앱을 다시 설치해야 하나요?

v0.2.0부터 Android 패키지 이름이 app.notium으로 바뀌어 이전 앱 위에 덮어 설치되지 않습니다.

  1. 이전 앱에만 있는 노트가 있으면 먼저 동기화를 마칩니다.
  2. 이전 Notium 앱을 삭제합니다.
  3. 새 앱을 설치하고 같은 계정으로 로그인한 뒤 기존 저장소에 연결을 선택합니다. 노트를 다시 받습니다.

Windows에서 SmartScreen 경고가 떠요.

설치 파일에 코드 서명이 없어 경고가 나올 수 있습니다. 추가 정보 → 실행을 선택하세요. 릴리스의 SHA256SUMS.txt로 파일 해시를 확인할 수 있습니다.

데이터를 지우려면?

데이터 삭제 안내를 확인하세요.
