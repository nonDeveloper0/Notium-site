개인정보처리방침

시행일: 2026년 11월 13일 · 운영자: nonDeveloper0

Notium은 개인용 로컬 우선 노트 앱입니다. 이 방침은 Windows·Android 앱과 Notium 안내 사이트에 적용됩니다. 운영자는 사용자의 노트를 보관하는 서버를 운영하지 않습니다.

현재 버전(v0.2.0)은 첫 베타입니다. 앱은 GitHub 릴리스와 Google Play로 배포합니다. Android 앱의 패키지 이름은 app.notium입니다.

1. 처리하는 정보와 목적

  • 노트·첨부·설정: 페이지, 폴더, 블록, 태그, 속성, 일지, 할 일, 첨부와 앱 설정을 작성·정리·검색·표시하기 위해 처리합니다.
  • 클라우드 계정 정보(선택): Google 또는 Microsoft로 연결할 때 계정 식별 정보를 연결 확인과 연결 상태 표시에 사용합니다. Google 로그인에서는 이메일도 받습니다. 비밀번호는 Notium이 받지 않습니다.
  • 동기화 데이터(선택): 노트 변경 이벤트, 스냅샷, 첨부 원본, 기기 이름·플랫폼·마지막 접속 시각을 사용자가 연결한 기기 사이에 동기화합니다.
  • AI 작업 기록(선택, Windows 데스크톱): 사용자가 연결한 AI 앱의 작업 결과를 기기 안에 기록하고 앱의 AI 작업 기록에 표시합니다.
  • 문의 정보: 공개 GitHub Issues에 사용자가 작성한 내용은 문의에 답하고 문제를 파악하는 데 이용될 수 있습니다.

2. 저장 위치와 보관 기간

노트의 실행 데이터는 기기의 SQLite 데이터베이스와 파일에 저장됩니다. 동기화를 켜면 동기화 데이터가 사용자가 고른 위치에 저장됩니다.

  • Google Drive: 사용자 본인 Drive의 앱 전용 숨김 공간(appDataFolder)
  • Microsoft OneDrive: 사용자 본인 OneDrive의 앱 폴더(Apps/Notium)
  • 로컬 폴더(Windows): 사용자가 직접 고른 폴더. 폴더가 다른 클라우드 서비스와 동기화되면 그 서비스의 정책이 적용됩니다.

운영자는 이 데이터의 사본을 보관하지 않습니다. AI 작업 기록과 앱 로그도 기기 안에만 저장됩니다.

로컬 데이터는 사용자가 앱에서 삭제하거나 기기의 앱 데이터를 지울 때까지 남습니다. 클라우드나 폴더의 동기화 데이터는 사용자가 직접 지울 때까지 남습니다. Google·Microsoft 서비스 자체의 처리와 보관에는 각 회사의 정책이 적용됩니다.

3. 클라우드 연결과 권한

클라우드 연결은 선택 기능입니다. 앱은 다음 권한을 각 목적에만 사용합니다.

Google

  • openid: Google 계정 로그인 사용자를 확인합니다.
  • email: 로그인 계정을 표시하고 연결 상태를 구분합니다.
  • https://www.googleapis.com/auth/drive.appdata: 사용자 본인의 Drive에 있는 Notium 전용 숨김 공간에 동기화 파일을 읽고 씁니다. 사용자의 다른 Drive 파일을 읽거나 변경할 수 있는 권한은 요청하지 않습니다.

Microsoft

  • Files.ReadWrite.AppFolder: 사용자 OneDrive의 Notium 앱 폴더에 동기화 파일을 읽고 씁니다. 다른 OneDrive 파일에는 접근하지 않습니다.
  • User.Read: 로그인한 계정을 확인하고 연결 상태를 표시합니다.
  • offline_access: 다시 로그인하지 않아도 동기화가 이어지도록 갱신 토큰을 받습니다.

인증 토큰은 Windows 자격 증명 관리자 또는 Android Keystore 등 기기의 OS 보안 저장소에 보관합니다. 앱에서 동기화 연결을 해제하면 기기에 저장된 토큰을 삭제합니다. Google은 이때 Google 서버의 접근 권한도 취소하고, OneDrive는 Microsoft 계정 설정에서 권한을 직접 제거해야 합니다. 연결을 해제해도 원격 동기화 데이터는 삭제되지 않습니다.

4. Google API Services User Data Policy — Limited Use

Notium은 Google API Services User Data Policy의 Limited Use 요구사항을 준수합니다. Google 데이터는 앱 화면에서 눈에 띄게 제공되는 기능을 제공하거나 개선하는 데만 사용합니다. 광고, 판매, 사용자 추적 또는 범용 AI 모델 학습에 사용하지 않습니다. 사람의 열람이나 제3자 전송은 정책이 허용하는 경우에만 이뤄집니다.

Notium's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Google API Services User Data Policy 전문

5. 제3자 제공

운영자는 노트나 클라우드 계정 데이터를 제3자에게 제공하지 않습니다. 동기화가 켜진 경우 데이터는 사용자의 Google 또는 Microsoft 계정, 또는 사용자가 고른 폴더에 저장됩니다. 앱은 HTTPS로 Google·Microsoft API와 통신합니다.

6. AI 연결 (Windows 데스크톱)

Notium은 이 PC에서 로컬 MCP 서버를 실행합니다. 사용자가 연결하면 앱이 AI 앱 자신의 설정 파일에 Notium 항목을 추가합니다. 지원하는 AI 앱은 다음과 같습니다.

  • Claude Desktop
  • Claude Code
  • Codex
  • Cursor
  • VS Code Copilot
  • Gemini CLI

설정 파일을 고치기 전에 같은 폴더에 백업 파일을 만듭니다. 백업은 최근 5개까지 남깁니다. 연결을 해제하면 Notium 항목만 지웁니다. Windows에서 Notium을 삭제하면 같은 방식으로 Notium 항목을 정리합니다.

연결한 AI 앱은 허용 범위에 따라 이 PC의 노트를 읽을 수 있습니다. 쓰기는 따로 허용해야 하며 승인된 변경만 반영됩니다. Notium은 AI 모델을 직접 호출하거나 노트를 AI 회사로 전송하지 않습니다. 사용자가 연결한 AI 서비스가 전달받은 내용은 해당 서비스의 정책과 설정을 따릅니다.

7. 기기 연결 해제와 데이터 삭제

동기화 기기를 연결 해제해도 그 기기의 로컬 노트나 클라우드의 노트는 원격 삭제되지 않습니다. 삭제를 원하면 로컬 데이터와 클라우드(또는 폴더) 데이터를 각각 지워야 합니다. 단계별 방법은 데이터 삭제 안내를 확인하세요.

Notium 계정은 없습니다. 운영자는 사용자 데이터를 보유하지 않으므로 운영자에게 요청해 처리할 데이터도 없습니다.

8. 앱 사용 기록, 광고 및 분석

Notium에는 광고 SDK, 분석 SDK, 사용 기록 수집, 추적 기능이 없습니다. 운영자에게 전송되는 앱 로그도 없습니다. 로그는 기기 안에만 저장됩니다.

9. 아동의 개인정보

Notium은 아동을 대상으로 설계되지 않았으며, 운영자는 아동의 개인정보를 의도적으로 수집하지 않습니다. 아동 개인정보가 공개 문의에 게시된 사실을 알게 되면 GitHub Issues에서 삭제를 요청할 수 있습니다.

10. 보안

앱 데이터는 기기에 저장되며 인증 토큰은 OS 보안 저장소에 보관합니다. 클라우드와의 통신은 HTTPS를 사용합니다. 기기 잠금과 백업 보안은 사용자가 관리해야 합니다. 노트 콘텐츠의 종단 간 암호화를 제공한다고 보장하지 않습니다.

11. 사용자의 권리

사용자는 자신의 데이터를 언제든 앱에서 보고, 내보내고, 삭제할 수 있습니다. 클라우드 권한은 Google 또는 Microsoft 계정 설정에서 철회할 수 있습니다. 운영자가 사용자 데이터를 갖고 있지 않으므로 열람·정정·삭제는 사용자가 직접 처리합니다.
