개인정보처리방침

시행일: 2026년 10월 21일 · 운영자: nonDeveloper0

이 방침은 Windows용 개인 노트 앱 Notium과 이 안내 사이트에 적용됩니다. Notium은 로컬 우선 앱이며, 운영자는 사용자의 노트를 보관하는 별도 서버를 운영하지 않습니다.

Google 계정 로그인과 Drive 동기화는 현재 개발 준비 중입니다. 아래 Google 관련 설명은 해당 기능을 제공하고 사용자가 연결했을 때 적용되는 처리 기준입니다. 기능 제공 전에 실제 구현과 이 방침의 일치 여부를 확인하고, 변경 사항이 있으면 방침을 갱신합니다.

1. 처리하는 정보와 목적

  • 노트와 첨부파일: 페이지 내용, 제목, 태그, 속성, 첨부파일과 관련 메타데이터를 기록·정리·검색·백업하기 위해 사용자 PC 및 사용자가 선택한 저장 위치에서 처리합니다.
  • Google 계정 정보: Google 연결 시 계정 식별자와 이메일 주소를 로그인한 계정 확인과 동기화 연결 표시에 사용합니다. Google 비밀번호는 Notium이 수집하지 않습니다.
  • 인증 정보: OAuth 접근 토큰과 갱신 토큰은 사용자가 허용한 범위의 Google API 호출 및 연결 유지에 사용합니다.
  • 동기화 데이터: 노트 변경 이력, 첨부파일, 장치 식별자·장치 이름 및 동기화 시각 등은 연결한 PC 사이에서 같은 기록을 유지하기 위해 처리합니다.

2. Google 접근 권한

openid와 email은 계정 확인에 사용합니다. https://www.googleapis.com/auth/drive.appdata는 사용자 본인 Google Drive의 Notium 전용 숨김 공간(appDataFolder)에 동기화 데이터를 저장하고 읽는 데 사용합니다. 이 권한으로 일반 Drive 파일 전체를 읽거나 수정할 수는 없습니다.

3. 저장 위치와 보안

노트 데이터베이스와 검색 인덱스, 썸네일 캐시는 PC 로컬에서 처리합니다. 첨부파일과 백업은 사용자가 선택한 저장 위치에 보관될 수 있습니다. Google 동기화를 연결하면 동기화에 필요한 노트 내용, 변경 이력과 첨부파일이 사용자 본인 Drive의 앱 전용 공간에 전송됩니다.

Google 연결 기능에서는 갱신 토큰을 Windows 자격 증명 관리자에, 접근 토큰을 메모리에 보관하도록 설계합니다. 토큰을 노트 데이터베이스나 로그에 기록하지 않습니다. Google API 통신에는 HTTPS를 사용합니다. 노트 콘텐츠의 종단 간 암호화는 현재 제공하지 않습니다.

4. 공유 및 Google API 데이터 이용 제한

운영자는 Google 사용자 데이터를 판매하거나 광고, 사용자 추적, 신용 평가 또는 범용 AI·머신러닝 모델 학습에 사용하지 않습니다. 앱 기능 제공에 필요한 Google 서비스와의 통신 외에 Google 사용자 데이터를 제3자에게 제공하지 않습니다. 사용자가 직접 문의에 포함한 내용을 제외하면 운영자가 노트를 열람하는 기능을 제공하지 않습니다.

Notium의 Google API에서 받은 정보 사용 및 다른 앱으로의 전송은 Limited Use 요구사항을 포함한 Google API Services User Data Policy를 준수합니다.

5. 보관 기간과 삭제

로컬 데이터는 사용자가 삭제할 때까지 사용자 PC와 선택한 저장 위치에 남습니다. 앱 제거만으로 데이터나 백업이 모두 삭제된다고 보장하지 않습니다. 완전한 삭제가 필요하면 앱을 종료하고 로컬 데이터, 첨부 저장소 및 별도 백업을 각각 삭제해야 합니다.

Google 연결 해제는 인증 정보를 폐기하는 동작이며 로컬 노트나 Drive의 앱 데이터를 자동으로 삭제하지 않습니다. Google 계정의 서드 파티 연결 관리에서 접근 권한을 철회할 수 있습니다. Drive의 앱 데이터 삭제는 Google Drive 설정의 앱 관리에서 Notium의 숨겨진 앱 데이터 삭제 항목을 이용합니다. Google UI에 따라 항목 이름은 다를 수 있습니다.

동기화 이력과 백업에 과거 내용이 남을 수 있으므로, 노트 하나를 삭제하는 것과 모든 사본의 완전 삭제는 다릅니다. 전체 삭제 전 모든 장치의 동기화를 중지하고, 연결된 장치의 로컬 사본과 클라우드 데이터·백업을 함께 정리해야 합니다. Google 서비스의 보관·삭제에는 Google 정책도 적용됩니다.

6. 안내 사이트와 외부 서비스

이 사이트는 GitHub Pages로 제공되며 자체 분석 도구, 광고 또는 문의 입력 폼을 사용하지 않습니다. 사이트 접속 시 GitHub가 보안·운영 목적으로 IP 주소 등 접속 정보를 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보처리방침과 Google 개인정보처리방침을 참고하세요.

7. 문의와 방침 변경

운영자 nonDeveloper0에게 GitHub Issues로 문의할 수 있습니다. 문의 내용은 문의 처리 목적으로 사용됩니다. Issues는 공개될 수 있으므로 개인정보나 노트 원문, 비밀번호, 토큰을 게시하지 마세요. 민감한 자료가 필요한 경우 먼저 자료를 포함하지 않은 문의를 남겨 전달 방법을 협의하세요.

처리 방식이 변경되면 이 페이지의 내용과 시행일을 갱신합니다.
