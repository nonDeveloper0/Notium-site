개인정보처리방침

시행일: 2026년 11월 1일 · 운영자: nonDeveloper0

Notium은 개인용 로컬 우선 노트 앱입니다. 이 방침은 Windows·Android 앱과 Notium 안내 사이트에 적용됩니다. 운영자는 사용자의 노트를 보관하는 서버를 운영하지 않습니다.

1. 처리하는 정보와 목적

  • 노트·첨부·설정: 페이지, 폴더, 블록, 태그, 속성, 일지, 할 일, 첨부와 앱 설정을 작성·정리·검색·표시하기 위해 처리합니다.
  • Google 계정 정보(선택): Google 로그인 때 계정 식별 정보와 이메일을 계정 확인 및 연결 상태 표시에 사용합니다. Google 비밀번호는 Notium이 받지 않습니다.
  • 동기화 데이터(선택): 노트 변경 이벤트, 스냅샷, 첨부 원본 및 기기 이름·플랫폼·마지막 접속 시각을 사용자가 연결한 기기 사이에 동기화합니다.
  • AI 작업 기록(선택, Windows 데스크톱): 사용자가 연결한 MCP 클라이언트의 작업 결과를 기기 안에 기록해 앱의 AI 작업 기록에 표시합니다.
  • 문의 정보: 공개 GitHub Issues에 사용자가 작성한 내용은 문의에 답하고 문제를 파악하는 데 이용될 수 있습니다.

2. 저장 위치와 보관 기간

노트의 실행 데이터는 기기의 SQLite 데이터베이스와 파일에 저장됩니다. 동기화를 켜면 동기화 데이터가 사용자 본인의 Google Drive 앱 전용 숨김 공간(appDataFolder)에 저장됩니다. Notium 운영자는 이 데이터의 사본을 보관하지 않습니다. AI 작업 기록과 앱 로그도 기기 안에 저장됩니다.

로컬 데이터는 사용자가 앱에서 삭제하거나 기기의 앱 데이터를 지울 때까지 남습니다. Drive 데이터는 사용자가 Google Drive에서 삭제할 때까지 남습니다. Google 서비스 자체의 처리·보관에는 Google 정책이 적용됩니다.

3. Google 사용자 데이터와 권한

Google 연결은 선택 기능입니다. 앱은 다음 권한을 각 목적에 사용합니다.

  • openid: Google 계정 로그인 사용자를 확인합니다.
  • email: 로그인 계정을 표시하고 연결 상태를 구분합니다.
  • https://www.googleapis.com/auth/drive.appdata: 사용자 본인의 Drive에 있는 Notium 전용 숨김 공간에 동기화 파일을 읽고 씁니다. 사용자의 다른 Drive 파일을 읽거나 변경할 수 있는 권한은 요청하지 않습니다.

인증 토큰은 Windows 자격 증명 관리자 또는 Android Keystore 등 기기의 OS 보안 저장소에 보관합니다. Google 연결 해제는 원격 동기화 데이터를 삭제하지 않습니다.

4. Google API Services User Data Policy — Limited Use

Notium은 Google API Services User Data Policy의 Limited Use 요구사항을 준수합니다. Google 데이터는 앱 화면에서 눈에 띄게 제공되는 기능을 제공하거나 개선하는 데만 사용합니다. 광고, 판매, 사용자 추적 또는 범용 AI 모델 학습에 사용하지 않습니다. 사람의 열람이나 제3자 전송은 정책이 허용하는 경우에만 이뤄집니다.

Notium's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Google API Services User Data Policy 전문

5. 제3자 제공 및 AI 연결

운영자는 노트나 Google 사용자 데이터를 제3자에게 제공하지 않습니다. Google 동기화가 켜진 경우 데이터는 사용자의 Google 계정에 저장됩니다.

Windows 데스크톱에서 사용자가 Claude 데스크톱, Claude Code 또는 Codex에 Notium MCP 서버를 직접 연결할 수 있습니다. 연결된 AI 앱은 허용 범위에 따라 사용자 PC의 노트를 읽고, 쓰기 기능이 켜졌을 때 승인된 변경을 반영할 수 있습니다. Notium은 AI 모델을 직접 호출하거나 노트를 AI 회사로 전송하지 않습니다. 사용자가 연결한 AI 서비스가 전달받은 내용은 해당 서비스의 정책과 설정을 따릅니다.

6. 기기 연결 해제와 데이터 삭제

동기화 기기를 연결 해제해도 그 기기의 로컬 노트나 Drive의 노트는 원격 삭제되지 않습니다. 삭제를 원하면 로컬 데이터와 Drive 데이터를 각각 지워야 합니다. 단계별 방법은 데이터 삭제 안내를 확인하세요.

  1. 앱에서 노트와 휴지통을 비웁니다.
  2. 앱을 삭제하고 앱 데이터 폴더를 삭제합니다. Windows: %APPDATA%\app.notium.local. Android: 앱 정보 → 저장공간 → 데이터 삭제.
  3. Google Drive 웹의 설정 → 앱 관리 → Notium → “숨겨진 앱 데이터 삭제”를 실행하고, Google 계정 보안 설정의 타사 액세스에서 Notium 권한을 삭제합니다.

운영자는 사용자 데이터를 보유하지 않으므로 운영자에게 별도 데이터 삭제를 요청해 처리할 데이터는 없습니다.

7. 앱 사용 기록, 광고 및 분석

Notium에는 앱 사용 기록 수집, 광고 또는 분석 SDK가 없습니다. 운영자에게 전송되는 앱 로그도 없습니다. 로그는 기기 안에만 저장됩니다.

8. 아동의 개인정보

Notium은 아동을 대상으로 설계되지 않았으며, 운영자는 아동의 개인정보를 의도적으로 수집하지 않습니다. 앱 사용 중 아동 개인정보가 공개 문의에 게시된 사실을 알게 되면 GitHub Issues에서 삭제를 요청할 수 있습니다.

9. 보안

앱 데이터는 기기에 저장되며 인증 토큰은 OS 보안 저장소에 보관합니다. 기기 잠금과 백업 보안을 사용자가 관리해야 합니다. 노트 콘텐츠의 종단 간 암호화를 제공한다고 보장하지 않습니다.
