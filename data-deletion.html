계정 및 데이터 삭제

시행일: 2026년 11월 13일 · 운영자: nonDeveloper0

Notium 계정은 없습니다. 운영자는 노트를 보관하는 서버도 운영하지 않습니다. 앱 데이터는 사용자의 기기에, 선택 동기화 데이터는 사용자의 Google Drive 또는 사용자가 고른 폴더(Windows)에 있습니다. 아래 위치에서 직접 삭제하세요. Android 앱(app.notium)도 같은 절차를 따릅니다.

삭제는 되돌릴 수 없습니다. 필요한 노트는 먼저 내보내거나 백업하세요. 기기 연결 해제와 로그인 권한 철회만으로 클라우드 데이터나 기기 안 노트가 자동 삭제되지는 않습니다. 사용 중인 모든 위치에서 삭제하세요.

1. 앱 안의 노트 삭제

  1. 각 기기에서 Notium을 열고 삭제할 노트를 휴지통으로 이동합니다.
  2. 휴지통을 비워 노트와 첨부 참조를 삭제합니다.

2. 기기의 앱 데이터 삭제

Windows

  1. Notium을 삭제합니다. (설정 → 앱 → 설치된 앱)
  2. 파일 탐색기 주소창에 %APPDATA%\app.notium.local을 입력해 폴더를 삭제합니다.

Android

  1. 설정 → 앱 → Notium → 저장공간 → 데이터 삭제를 실행합니다.
  2. 앱을 삭제합니다.

직접 만든 백업이나 내보낸 파일이 있으면 보관 위치에서 따로 삭제하세요.

3. Google Drive 동기화 데이터와 접근 권한 삭제

  1. 웹에서 Google Drive를 열고 설정 → 앱 관리 → Notium → “숨겨진 앱 데이터 삭제”를 선택합니다.
  2. Google 계정 → 보안 → 타사 액세스에서 Notium 권한을 삭제합니다.

4. 로컬 동기화 폴더 삭제

동기화 폴더로 고른 폴더가 있으면 그 폴더 안의 Notium 동기화 파일을 삭제하세요. 폴더가 다른 클라우드 서비스와 동기화되고 있다면 그 서비스의 휴지통까지 비우세요.

5. AI 앱 설정에서 Notium 항목 제거 (Windows)

  1. 자동: Windows에서 Notium을 삭제하면 설치 제거 프로그램이 Claude Desktop, Claude Code, Codex, Cursor, VS Code Copilot, Gemini CLI 설정 파일의 Notium 항목을 지웁니다. 업데이트 중에는 지우지 않습니다.
  2. 앱에서: 삭제 전에 Notium 설정 → AI 연결에서 연결을 해제해도 됩니다.
  3. 직접: 자동 정리가 실패했다면 각 AI 앱 설정 파일에서 notium 항목을 지우세요. 파일을 고칠 때 만든 백업(*.notium-backup-*)이 같은 폴더에 남아 있을 수 있으며 직접 삭제해도 됩니다.

운영자 보관 데이터

운영자는 노트, 첨부, 클라우드 동기화 데이터 또는 앱 사용 로그를 보관하지 않습니다. 따라서 운영자가 대신 삭제할 사용자 데이터는 없습니다. 공개 Issues에 게시한 문의 내용의 삭제가 필요하면 해당 이슈를 삭제하거나 아래 문의 창구로 요청하세요.
