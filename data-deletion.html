계정 및 데이터 삭제 요청

시행일: 2026년 11월 1일 · 운영자: nonDeveloper0

Notium은 별도의 Notium 계정이나 노트 보관 서버를 운영하지 않습니다. 앱 데이터는 기기에, 선택 동기화 데이터는 사용자의 Google Drive에 저장됩니다. 각 위치에서 직접 삭제하세요.

1. 앱 안의 노트 삭제

  1. 각 기기에서 Notium을 열고 삭제할 노트를 휴지통으로 이동합니다.
  2. 휴지통을 비워 노트와 첨부 참조를 삭제합니다.

2. 기기의 앱 데이터 삭제

  1. Notium 앱을 삭제합니다.
  2. Windows에서는 사용자 앱 데이터 폴더 %APPDATA%\app.notium.local을 삭제합니다.
  3. Android에서는 설정 → 앱 → Notium → 저장공간 → 데이터 삭제를 실행합니다.
  4. 별도로 만든 백업이 있다면 보관 위치에서 직접 삭제합니다.

3. Google Drive 동기화 데이터와 접근 권한 삭제

  1. 웹에서 Google Drive를 열고 설정 → 앱 관리 → Notium → “숨겨진 앱 데이터 삭제”를 선택합니다.
  2. Google 계정 → 보안 → 타사 액세스에서 Notium 권한을 삭제합니다.
  3. 동기화한 각 기기의 로컬 데이터도 위 2단계에 따라 삭제합니다.
기기 연결 해제와 Google 로그인 권한 철회만으로 Drive 데이터나 기기 안 노트가 자동 삭제되지는 않습니다. 연결된 모든 위치에서 삭제 절차를 완료하세요.

운영자 보관 데이터

운영자는 노트, 첨부, Google 동기화 데이터 또는 앱 사용 로그를 보관하지 않습니다. 따라서 운영자가 대신 삭제할 사용자 데이터는 없습니다. 공개 Issues에 게시한 문의 내용의 삭제가 필요하면 해당 이슈를 삭제하거나 아래 문의 창구로 요청하세요.

문의

Notium 공개 Issues에 문의할 수 있습니다. 공개 게시물에는 노트 내용, 이메일 주소 등 개인정보, 비밀번호 또는 인증 토큰을 올리지 마세요.
