베타 안내. Notium v0.2.0은 첫 공개 베타입니다. 개인이 만든 베타 버전이며, 있는 그대로 제공됩니다. 프로그램 오류, 동기화 문제, 기기 고장, 클라우드 계정·용량 문제 등으로 노트나 첨부 파일이 손상되거나 사라질 수 있습니다. 그 경우에도 개발자는 복구하거나 책임지지 않습니다. 중요한 자료는 항상 따로 백업해 두세요. PC에서는 설정 → 데이터 → 백업에서 백업 파일을 만들 수 있습니다.

1. 앱과 배포 경로

Notium은 개인 노트를 작성·정리하는 Windows 데스크톱 및 Android 앱입니다. 앱은 다음 경로로 배포합니다.

  • GitHub 릴리스: Windows 설치 파일(NSIS, 앱 안 업데이트 포함)과 Android APK. APK는 사용자가 직접 설치·업데이트합니다.
  • Google Play: Android 앱. 설치와 업데이트는 Google Play 정책과 약관에 따릅니다.

iOS 앱은 현재 제공하지 않습니다. 버전과 제공 파일은 릴리스 페이지에 표시합니다. 사용자는 파일의 출처와 버전을 확인한 뒤 설치해야 합니다.

2. 사용자 콘텐츠

사용자가 작성하거나 첨부한 자료의 권리는 사용자 또는 해당 권리자에게 있습니다. 사용자는 저장할 권한이 있는 자료만 사용해야 합니다. 앱 이용으로 콘텐츠 소유권이 운영자에게 이전되지 않습니다.

3. 저장, 동기화 및 백업

노트와 첨부는 기기에 저장됩니다. 사용자가 선택하면 Google Drive 앱 전용 숨김 공간, Microsoft OneDrive 앱 폴더 또는 사용자가 고른 폴더(Windows)로 동기화할 수 있습니다. 동기화는 독립적인 백업을 대신하지 않으며 네트워크, 기기, 외부 서비스 상태에 따라 지연되거나 중단될 수 있습니다. 중요한 자료는 별도 위치에 정기적으로 백업하세요.

4. 사용자의 계정과 책임

사용자는 자신의 Google·Microsoft 계정, 저장 용량, 접근 권한, 동기화 폴더와 기기 보안을 직접 관리해야 합니다. 계정 정지, 용량 부족, 권한 철회, 폴더 삭제 등으로 생긴 문제는 운영자가 해결하거나 책임지지 않습니다. 해당 서비스의 약관과 정책이 따로 적용됩니다.

5. 자동 업데이트와 Android 설치

Windows 앱은 업데이트를 확인하고 제공된 업데이트를 설치할 수 있습니다. 업데이트 시 기능, 호환성 또는 저장 데이터 구조가 바뀔 수 있습니다. v0.2.0부터 Android 패키지 이름이 app.notium으로 바뀌어 이전 Android 앱 위에 덮어 설치되지 않습니다. 이전 앱을 지우기 전에 동기화를 마치고 백업하세요.

6. 선택적 AI 연결

Windows 데스크톱 AI 연결은 사용자가 선택하고 설정하는 기능입니다. 사용자가 연결하면 Notium이 해당 AI 앱(Claude Desktop, Claude Code, Codex, Cursor, VS Code Copilot, Gemini CLI)의 설정 파일에 Notium 항목을 추가합니다. 고치기 전에 백업 파일을 만들지만, 사용자는 자신의 AI 앱 설정을 직접 확인할 책임이 있습니다. 연결한 AI 앱은 사용자 PC 안의 노트에 접근하며, 읽기·쓰기 범위는 Notium 설정과 승인 절차를 따릅니다. Notium은 AI 모델을 직접 호출하지 않습니다. 사용자가 AI 앱에 제공한 정보의 외부 처리와 AI 결과의 사용은 사용자의 책임이며 해당 AI 서비스 약관과 개인정보 정책이 적용됩니다.

7. 보증의 부인과 책임 제한

앱과 다운로드는 관련 법률이 허용하는 범위에서 현재 상태로 제공되며 어떤 보증도 하지 않습니다. 운영자는 오류가 없거나 중단 없이 동작하거나 모든 기기·환경과 호환된다고 보증하지 않습니다. 법률이 허용하는 범위에서 운영자는 앱 사용 또는 사용 불가로 발생한 간접·우발·특별·결과적 손해, 데이터 손실 또는 영업 손실에 책임을 지지 않습니다. 이 조항은 법률상 배제할 수 없는 보증이나 책임을 제한하지 않습니다.

8. 개인정보와 이용 중단

개인정보 처리는 개인정보처리방침을 따릅니다. 사용자는 앱 사용을 중단하고 Google·Microsoft 권한을 철회할 수 있습니다. 앱 삭제나 연결 해제만으로 로컬·클라우드 사본이 모두 삭제되지는 않으므로 데이터 삭제 안내를 따르세요.

9. 약관 변경

앱 제공 방식이나 관련 법령이 바뀌면 이 페이지를 갱신하고 시행일을 표시합니다.
