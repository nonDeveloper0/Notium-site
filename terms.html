1. 앱과 다운로드

Notium은 개인 노트를 작성·정리하는 Windows 데스크톱 및 Android 앱입니다. Windows 설치 파일은 NSIS 설치 프로그램으로 제공되며 자동 업데이트 기능을 포함합니다. Android 앱은 APK 파일로 직접 배포합니다. iOS 앱은 현재 제공하지 않습니다. 버전과 제공 파일은 릴리스 페이지에 표시합니다.

2. 사용자 콘텐츠

사용자가 작성하거나 첨부한 자료의 권리는 사용자 또는 해당 권리자에게 있습니다. 사용자는 저장할 권한이 있는 자료만 사용해야 합니다. 앱 이용으로 콘텐츠 소유권이 운영자에게 이전되지 않습니다.

3. 저장, 동기화 및 백업

노트와 첨부는 기기에 저장됩니다. 사용자가 선택해 Google Drive 동기화를 연결하면 본인 계정의 앱 전용 숨김 공간을 이용합니다. 동기화는 독립적인 백업을 대신하지 않으며 네트워크, 기기, 외부 서비스 상태에 따라 지연되거나 중단될 수 있습니다. 중요한 자료는 별도 위치에 정기적으로 백업하세요.

4. 자동 업데이트와 APK

Windows 앱은 업데이트를 확인하고 제공된 업데이트를 설치할 수 있습니다. 업데이트 시 기능, 호환성 또는 저장 데이터 구조가 바뀔 수 있습니다. Android 사용자는 릴리스에서 APK를 내려받아 기기 설정에 따라 직접 설치·업데이트해야 합니다. APK 설치는 사용자가 파일의 출처와 버전을 확인한 뒤 진행해야 합니다.

5. 선택적 AI 연결

Windows 데스크톱 AI 연결은 사용자가 선택하고 설정하는 기능입니다. 연결한 AI 앱은 사용자 PC 안의 노트에 접근하며, 읽기·쓰기 범위는 Notium 설정과 승인 절차를 따릅니다. Notium은 AI 모델을 직접 호출하지 않습니다. 사용자가 AI 앱에 제공한 정보의 외부 처리와 AI 결과의 사용은 사용자의 책임이며 해당 AI 서비스 약관과 개인정보 정책이 적용됩니다.

6. 보증의 부인과 책임 제한

앱과 다운로드는 관련 법률이 허용하는 범위에서 현재 상태로 제공됩니다. 운영자는 오류가 없거나 중단 없이 동작하거나 모든 기기·환경과 호환된다고 보증하지 않습니다. 법률이 허용하는 범위에서 운영자는 앱 사용 또는 사용 불가로 발생한 간접·우발·특별·결과적 손해, 데이터 손실 또는 영업 손실에 책임을 지지 않습니다. 이 조항은 법률상 배제할 수 없는 보증이나 책임을 제한하지 않습니다.

7. 개인정보와 이용 중단

개인정보 처리는 개인정보처리방침을 따릅니다. 사용자는 앱 사용을 중단하고 Google 권한을 철회할 수 있습니다. 앱 삭제나 연결 해제만으로 로컬·Drive 사본이 모두 삭제되지는 않으므로 데이터 삭제 안내를 따르세요.

8. 약관 변경

앱 제공 방식이나 관련 법령이 바뀌면 이 페이지를 갱신하고 시행일을 표시합니다.

9. 문의
